# ai-weapon

> 把 AGI 路上的实战经验，做成图文并茂的在线手册。

这是 HANK（五花肉，公众号「算力白肉」作者）的 **AGI 经验沉淀站**。
不讲理论、不堆术语——记录的都是他在用 AI 工具、踩坑、做决策时的具体判断。

## 在线看

**[https://ai-weapon.aichi.food/](https://ai-weapon.aichi.food/)**

GitHub Pages + 自管域构建。站点就是仓库当前这份静态产物，

## 这个仓库装的是什么

```
index.html     # 单页入口
css/style.css  # 样式
js/app.js      # 交互
```

纯静态站，**双击 `index.html` 就能本地预览**，不依赖 Node / Python / 任何 build 工具。
